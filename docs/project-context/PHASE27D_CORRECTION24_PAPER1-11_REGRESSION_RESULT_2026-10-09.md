# Phase 27D Correction 24 — Paper1-11 Regression Result

Date: 2026-10-09

## Source test

JEE Advanced 2016 Paper 1-11 was regenerated by the user using the then-current
CBTGen conversion prompt and imported into the latest project.

## Observed result

The import validator reported 105 errors:

- mathematical notation flattened into ordinary `<text>` across many question/option content blocks;
- `NAT_VALUE_MISSING` for Q15;
- `MULTI_CHOICE_ANSWER_COUNT` for Q28.

## Interpretation

The project-side semantic gate was correctly detecting the generated output. The
regeneration also demonstrated that response-mode and package/asset corrections
were effective, but the external conversion still chose ordinary `<text>` for
mathematical regions.

Q15 and Q28 remain source-answer evidence issues and must not be solved or guessed.

## Correction 24 response

The universal conversion prompt now contains an explicit closed-set rule:
mathematical regions MUST be represented by structured `<math>`/MathML or an exact
math-only visual fallback. Ordinary `<text>` is not a valid mathematical
representation. A final zero-tolerance mathematical preflight requires both:

- unresolved mathematical regions = 0
- flattened mathematical regions = 0

The semantic validator was also hardened so a valid `<math>` sibling cannot mask a
separate flattened mathematical `<text>` node in the same content block.

Paper1-11 remains regression evidence and is not modified or promoted to best version.
